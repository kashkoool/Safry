# تحديث البيانات واللغتين — 2026-09-26

- أضيفت حقول أسماء الشركات العربية والإنجليزية إلى قاعدة البيانات والتسجيل والتعديل والعرض.
- أضيفت حقول ترجمة الخدمات: العنوان والوصف والمدينة والتفاصيل النصية. الأرقام والسعات والتواريخ والأسعار لها مصدر واحد ولا تتغير بسبب اللغة.
- أضيفت ترجمة تسميات الواجهات والإدارة والحالات ورسائل النظام المعروفة، مع حفظ اللغة ومزامنتها بين التبويبات واتجاه العرض وتنسيق التاريخ والعملة.
- محتوى المستخدم غير المترجم يعرض كما أدخله، ويمكن إضافة ترجمته من محرر الخدمة.

## استبدال البيانات

بعد موافقة المستخدم الصريحة، حُذفت 10 خدمات/برامج قديمة، منها «رحلة 2 اوكتوبر»، وحجز تجريبي واحد، واستُبدلت بـ8 خدمات ثنائية اللغة و3 حجوزات بحالات مختلفة.

حُفظت حسابات المستخدمين والموظفون والأدوار، وخدمة «رحلة عمرة» وحجزاها. لم تُمسح قاعدة البيانات.

النسخة السابقة حُفظت محلياً على جهاز المطوّر الذي نفّذ التحديث فقط (المجلد `backend/backups/` مُتجاهَل في Git ولا يوجد في هذا المستودع، لذلك لا يمكن التحقق من وجودها أو الاسترجاع منها هنا). تحتوي سجلات العمل المحذوفة والروابط والمنشآت، وليست نسخة كاملة لقاعدة البيانات. تحفظ للاسترجاع المراجع ولا تنشر مع المشروع.

سكربت `pnpm --dir backend demo:refresh` يعرض المعاينة فقط دون `--apply`؛ يرفض إعادة التنفيذ إذا كانت البيانات الجديدة موجودة. تم تحديث تهيئة المشروع لتستخدم الكتالوج الجديد بدلاً من إعادة إنشاء العينات القديمة.
